# Sonora Instruments

Instruments that earn the encore.

**Style:** Warm Analog Editorial  
**Diamond batch:** 4 (#34)  

## Run locally

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build:

```bash
npm run build
npm start
```

## Features

- Homepage film (autoplay muted loop + poster fallback)
- AI assistant with niche Q&A
- Offers / coupon `ENCORE10`
- Reviews, deep catalog (search/filter/sort), PDP specs & FAQ
- Cart → Stripe-style checkout → success
- Niche desk: `/studio` (Studio)
- Locations, journal, account/loyalty teaser, newsletter
- Soft motion + reduced-motion respect
